Preguntas frecuentes

¿Qué datos necesitan para pasarme un presupuesto?

La fecha, el tipo de evento, la cantidad de invitados y el lugar. Si ya tenés colores o una temática, contanos también.

¿Con cuánta anticipación conviene consultar?

Cuanto antes, mejor: así reservamos la fecha y hay tiempo para preparar la ambientación.

¿Puedo alquilar solo mantelería, mesas o vajilla?

Sí, también podés consultar solo por el alquiler. Te confirmamos qué hay disponible para tu fecha.

¿Alquilan vestimenta típica para actos escolares?

Sí, disfraces y vestimenta típica para los actos del colegio. Consultá talles y fechas por WhatsApp.
