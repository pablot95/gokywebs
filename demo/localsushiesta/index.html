El oficio

Una obsesión simple

LocalSushiEsta nace de una obsesión simple: que cada roll salga igual de bien, pedido tras pedido. Arroz en su punto, pescado fresco y un corte parejo — sin atajos, ni siquiera cuando el pedido es para ya.

El proceso

El corte

  1. 01

    El nori

    Una hoja, tostada y crocante: la base de todo roll.

  2. 02

    El arroz

    Grano por grano, con el punto justo de vinagre — ni pegajoso ni suelto.

  3. 03

    El relleno

    Salmón, langostinos, palta o queso crema: la combinación es la firma de cada roll.

  4. 04

    El armado

    Se enrolla firme, una sola vez — ahí se juega la forma final.

  5. 05

    El corte

    Piezas parejas, del mismo grosor. El detalle que se nota en el primer bocado.
