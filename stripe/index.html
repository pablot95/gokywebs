Cómo activar las credenciales de producción de Stripe

Guía paso a paso, de principio a fin, para activar la cuenta de Stripe en modo producción (Live) y empezar a recibir pagos reales en tu sitio.

1

Crear (o ingresar a) la cuenta de Stripe

Si todavía no tenés cuenta, creala en:

https://dashboard.stripe.com/register

Si ya tenés una cuenta de Stripe, ingresá directamente al panel:

https://dashboard.stripe.com/login

Usá un email al que tengas acceso permanente: ahí van a llegar las notificaciones de pagos, alertas de seguridad y verificación de la cuenta.

2

Activar la cuenta (datos del negocio)

Recién creada, la cuenta arranca en modo Test. Para poder cobrar de verdad hay que activarla completando los datos del negocio. Stripe va a pedir, entre otras cosas:

  • Tipo de negocio (persona física / monotributo / sociedad) y rubro.
  • Datos fiscales: CUIT, razón social, dirección.
  • Datos del titular de la cuenta (nombre, fecha de nacimiento, documento).
  • Cuenta bancaria (CBU/CVU) donde Stripe va a depositar lo cobrado.
  • Sitio web o descripción del producto/servicio que se vende.

Este paso lo tiene que hacer el dueño de la cuenta/negocio, ya que son sus datos personales y bancarios. Una vez enviada la información, Stripe puede tardar de minutos a un par de días en revisarla y activar el modo Live.

Importante: hasta que la cuenta no esté activada, las claves "Live" van a estar visibles pero los pagos reales pueden quedar retenidos o rechazados. Mientras tanto se puede seguir probando todo con las claves de Test.
3

Obtener las claves de API (modo Live)

Dentro del Dashboard, andá a Desarrolladores → Claves de API (en inglés: Developers → API keys):

https://dashboard.stripe.com/apikeys

  1. Arriba a la derecha, asegurate de que el switch "Modo de prueba" / "Test mode" esté desactivado (esto muestra las claves de producción/Live).
  2. Vas a ver dos valores:
    • Clave publicable / Publishable key (empieza con pk_live_...)
    • Clave secreta / Secret key (empieza con sk_live_...) — para verla hay que hacer clic en "Revelar clave en vivo".
Copiá ambos valores y agregalos en tu sitio. En admin -> Configuración -> Stripe. Vas a ver dos campos para completar: Publishable Key y Secret Key.
Nunca compartas la Secret key por chat, mail o la subas a un repositorio público: con ella se pueden generar cobros desde la cuenta. Si alguna vez se filtra, se puede regenerar ("roll key") desde esta misma pantalla.
4

Configurar el Webhook (confirmación de pagos)

Para que el sitio se entere automáticamente cuando un pago se aprueba, hay que crear un endpoint de webhook:

  1. Andá a Desarrolladores → Webhooks y hacé clic en "Agregar endpoint" / "Add endpoint".
  2. En "URL del endpoint" pegá la dirección del sitio que te pasamos (algo del estilo https://tusitio.com/api/stripe-webhook.php).
  3. Seleccioná los eventos a escuchar, como mínimo: checkout.session.completed y payment_intent.succeeded.
  4. Guardá el endpoint y copiá el "Signing secret" que aparece (empieza con whsec_...).
Ese whsec_... también se carga en admin -> Configuración -> Stripe, en el campo Webhook Secret.

🎉 Producción activada

Con estos pasos, la cuenta de Stripe queda activada y lista para reemplazar las claves de prueba por las de producción. Si en algún momento necesitás rotar una clave por seguridad, solo hace falta repetir el paso 3 (o el 4 para el webhook) y actualizar el valor en admin -> Configuración.
