Cómo funciona la conexión

Tu web se conecta con el portal de noticias que nos indiques para traer las notas nuevas de forma automática. Cada una llega como borrador a tu panel: vos decidís cuándo publicarla, para no perder el control editorial de tu sitio. La forma exacta de conectar (feed RSS, API o webhook) depende de lo que ofrezca el portal de origen — la definimos juntos ya arrancado el proyecto.
